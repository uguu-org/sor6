Fernado Sor Opus 6, No 11

This file is meant to resemble a regular guitar tab file, with a few
extra features:

- Tuning information is specified in the "tuning" lines.

- Timing information is specified in the "ms_per_tick" lines.  The "timing"
  lines below record what was in the original score, but it's purely
  informational and is not used by the conversion script.

- All notes are aligned to some '+' mark above the measures.  Each '+'
  marks the tick of when the aligned notes would play.

- Each note is specified as a positive integer, which is the fret position.
  '0' means open string.

- Rest notes as specified as 'x'.  Rest notes causes previous note on
  the same string to be cut off early.

- Notes followed by '!' are played at full velocity.  All other notes
  are played at reduced velocity.

- Repeat sections are intentionally not supported.  Instead, songs with
  repeat sections are preprocessed with M4 to expand those sections.

- None of the special guitar techniques are supported (no harmonics,
  glissandos, etc).  Sor's Opus 6 don't use most special techniques, and
  playing slurs as regular notes doesn't sound too bad, so I have
  implemented just the bare minimum.

  What we have here is a simple system that allows for songs to be easily
  edited with text editors, and played back with a straightforward
  implementation and minimal sound samples.  We will probably go with
  standard MIDI files if we need to support more complicated songs.

Tab data here has been verified against the PDF found here:
https://classicalguitarshed.com/sm-sor-op6-no11/
https://www.thisisclassicalguitar.com/fernando-sor-studies-free-sheet-music-pdfs/

the first version for those measures because they felt more consistent.
